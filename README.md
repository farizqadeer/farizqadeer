> **LangGraph · FastAPI · Docker · Gemini API · Railway**

Production multi-tool LangGraph agent with four tools — order tracking, FAQ search, product lookup, and human escalation. Features per-session persistent memory via checkpointing, FastAPI backend with Pydantic validation, and full CI/CD pipeline with pytest before every deployment.

---

#### ⚖️ [LegalMind RAG System](https://github.com/farizqadeer/legalmind-rag-api)
> **ChromaDB · Gemini · FastAPI · Docker · Semantic Chunking**

End-to-end RAG system for legal document Q&A using semantic chunking, hybrid search, and source citation with confidence scoring. Containerized FastAPI service with automated document ingestion baked into the Docker build — ready for one-command cloud deployment.
